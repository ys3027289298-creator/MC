# 荒原方格：失落地脉（Wasteland Grids: Lost Leyline）

一款纯前端、可在浏览器中运行的三维方块沙盒生存建造游戏。使用 **TypeScript + Vite + Three.js + Vitest** 开发，无需后端服务。

在一片随机生成的荒原中，玩家需要采集资源、制作工具、建立据点、探索地下晶洞、修复废弃能源塔、找到失落观测站中的地脉坐标，并在最终夜袭中守护能源塔、唤醒失落地脉。

## 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 启动开发服务器（默认 http://localhost:5173，自动打开浏览器）
```

其它命令：

```bash
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览生产构建
npm test           # 运行全部 Vitest 测试（共 80 个用例）
```

## 10–15 分钟推荐演示路线

推荐种子：**`LEYLINE-2049`**（开始菜单默认值，固定种子生成世界一致）。

1. 出生后采集枯木、碎石和荆棘，做出 2 块木板、绑带、**石质采集锤**、**燧石切割斧**。
2. 制作并放下**工作台、储物箱、泥炭火盆**，用木板围出庇护所（任务 2）。
3. 在工作台制作**手摇挖掘钻**，前往地图东南的**地下晶洞**（坐标约 `38, -40`），下井取得 **2 个能源晶体**。
4. 前往西北高地的**废弃能源塔**（约 `-52, 28`），制作电池组与**塔心中继器**，对塔顶中继器按 `E` 修复。
5. 前往东方的**失落观测站**（约 `56, 8`），在储物箱取得**地脉坐标图**与遗迹铭牌。
6. 回工作台制作**地脉探测器**与**信号引灯**。
7. 前往北方**地脉禁区**（约 `4, 96`），对准**地脉核心座**按 `E`，进入 90 秒最终防守。
8. 守住能源塔后信号传输完成，根据建造、装备、击杀和存活情况进入不同结局。

录屏过程中可依次展示：移动跳跃、昼夜与天气变化、方块采集进度、制作与工作台门控、放置方块与绿色/红色轮廓预览、开门、储物箱、敌人追击与视线阻挡、飞镖远程战斗、任务推进与结局结算。

## 玩法系统

- **世界生成**：基于确定性值噪声 + mulberry32 随机数；草地/岩地/沙地/浅水/深水/高地，区块大小 16×16、高度 64，按玩家位置流式加载与释放。洞穴、矿脉（铁/铜/煤/晶簇）、枯木、荆棘、流木、废墟。三处特殊地点与最终禁区均带资源、机关或敌人：
  - **失落观测站**（废墟建筑 + 储物箱：地脉坐标图、遗迹铭牌）
  - **地下晶洞**（晶簇矿洞 + 储物箱：能源晶体、浮影尘；洞内有裂脊蝎）
  - **废弃能源塔**（熔渣高地，塔顶中继器 + 储物箱：能源塔残片）
- **方块**：30 种方块，不同颜色、硬度、采集工具、掉落、透明度、发光。建筑方块有结构耐久，可被袭击破坏，可用修理器修复。
- **工具**：石质采集锤/锻铁重锤、燧石切割斧/锻铁阔斧、手摇挖掘钻/晶能动力钻、手持照明棒、喷补修理器；均有耐久、采掘力、伤害，逐级升级。
- **制作**：基础徒手配方与工作台配方；遗迹铭牌解锁高级配方；主线阶段门控任务道具；材料不足/需要工作台/任务未解锁均有明确中文提示。
- **生存**：生命、体力、饱食、体温（理想 37℃）、照明安全值；奔跑/跳跃/挖掘消耗体力，饥饿掉血，夜晚、高地、地下、极寒降低体温，火盆/光晶/照明棒/庇护所可以保暖与提供安全光。
- **昼夜天气**：240 秒一天，太阳轨迹、天空/雾/光照/阴影实时变化；晴天、暴雨（闪电）、沙尘（低能见度减速升温）、极寒（失温）真实影响视野、速度、温度和敌人活跃度。
- **敌对生物**：暮行兽（夜袭、高生命）、裂脊蝎（洞穴）、浮影（夜间高速）；具备巡逻→发现→追击→攻击→失去视线脱离的状态机，会被墙壁和玩家建筑阻挡，死亡掉落材料。
- **据点建筑**：墙、地板、玻璃、金属板、砖、门（可开合且改变碰撞）、储物箱（40 格持久化）、工作台、火盆、电池组、导管、中继器、地脉核心座。
- **动态事件（8 种）**：资源枯竭、据点遭袭、天气突变、洞穴坍塌、能源泄漏、商旅补给箱、遗迹机关启动、敌人迁徙；都会真实改变方块、天气、敌人或物品，可在 `J` 日志查看。
- **任务与结局**：10 个主线阶段；开始时可选择“固守工事 / 拾荒奇兵”两条路线，结局标题和文本不同，并按准备程度分为不熄灯塔/拾荒者黎明、断续信号、惨胜黎明、荒原余烬。
- **存档**：多槽位本地存档（见下节）。包含种子、玩家位置与视角、背包、快捷栏、护具、生存状态、时间天气、方块修改、门状态、建筑耐久、储物箱、掉落物、任务、事件、统计。

## 存档槽位

游戏使用 `localStorage` 提供 **3 个手动槽位 + 1 个自动保存槽位**，无需后端与账号：

- **主菜单**展示全部槽位：空闲/已有/已损坏、种子、任务路线、荒原天数、游玩时长与最近保存时间；可逐个「载入」或「删除」（删除有确认，且不影响其它槽位）。
- **暂停菜单 → 保存进度**可将当前进度另存为任一手动槽位；覆盖已有槽位前会弹出确认，取消则不改动任何数据。「自动保存」槽位由系统独占，每 30 秒写入一次（关闭页面前也会写入），不能手动覆盖。
- **继续游戏**会读取你最近使用的槽位（无标记时取最近保存的槽位）；也可以直接在主菜单点选某个槽位载入。
- **数据结构**：槽位存放在版本化外壳 `wasteland-grids-save-slots-v2`（`version: 2`，含 `currentSlot` 标记与各槽位的 `summary + save`）中，每次写入都是单次完整 JSON 替换，不会留下半个槽位。槽位内的游戏数据仍是原有 `version: 1` 的 `GameSave`，字段未做任何改动。
- **旧版兼容**：旧版单存档键 `wasteland-grids-save-v1` 仍可读取。检测到旧存档时主菜单会显示提示，并在你选择「继续游戏」或执行保存时自动迁移到第一个空闲手动槽位（迁移后删除旧键）；若手动槽位已满，旧存档会原样保留，绝不静默丢弃。旧存档缺少槽位元数据时会用安全摘要（默认天数/时长/时间）生成展示。
- **损坏隔离**：单个槽位损坏只影响该槽位（主菜单标记「已损坏」，其余槽位照常载入）；整个槽位列表损坏时按空槽位安全显示并给出明确错误。读取失败不会污染当前运行状态。
- **清除存档**：读取失败页面提供「清除存档并重新开始」，会同时移除槽位外壳与旧版单存档键；暂停菜单「重新开始」只删除当前正在使用的槽位。

```

src/
  main.ts                  启动入口

  game/
    rng.ts                 确定性 RNG 与值噪声
    blocks.ts              30 种方块定义

    recipes.ts             全部配方与解锁条件
    inventory.ts           背包、堆叠、拆分、丢弃、装备、耐久
    world.ts               区块、地形/洞穴/矿脉/特殊地点生成、存取

    survival.ts            生存状态、昼夜、天气

    quests.ts              主线、路线、结局判定
    save.ts                localStorage 存档：v1 GameSave + v2 多槽位外壳、摘要、迁移、损坏隔离
    engine.ts              游戏总控：输入、战斗、相机、HUD、存档
  render/
    mesher.ts              区块网格生成（面剔除、顶点色、水面）
    renderer.ts            Three.js 场景、光照、阴影、敌人/掉落/天气特效
  ui/
    ui.ts                  HUD、提示、状态条、热栏渲染
    ui-dom.ts              主菜单、设置、错误、重开确认
    panels.ts              背包/制作/日志/储物箱/暂停/死亡/结局
tests/                     Vitest 测试（10 个文件，80 个用例）
```

## 测试覆盖

`npm test` 运行：

- 种子确定性、噪声范围、世界一致性（`world.test.ts`）
- 区块加载/卸载、三处特殊地点资源与结构
- 玩家移动、落地、墙壁碰撞、跳跃、体素射线（`physics.test.ts`）
- 方块放置限制、禁止放入身体、支撑检测、破坏掉落、工具速度、门碰撞、建筑耐久（`blocks.test.ts`）
- 背包堆叠、不混放、容量、拆分、丢弃、工具耐久、装备（`inventory.test.ts`）
- 配方材料/工作台/铭牌/任务门控（`crafting.test.ts`）
- 昼夜、天气、饥饿、失温、火盆庇护、减速、伤害防御（`survival.test.ts`）
- 敌人发现/追击/攻击间隔、墙体阻挡与视线、受击/死亡掉落（`enemies.test.ts`）
- 主线推进、双路线与多结局、事件实际改变世界、建筑存档与碰撞、存档损坏处理（`quests-events-save.test.ts`）
- 多槽位存档：槽位独立、自动槽位保护、覆盖/删除/标记、坏槽位隔离、坏外壳、旧版迁移与安全摘要（`save-slots.test.ts`）
- 页面级链路：主菜单选槽载入 engine、暂停菜单另存、覆盖确认与取消、旧存档继续、删除槽位、重开与跨刷新一致性（`menu-slots-flow.test.ts`）
