# 荒原方格：失落地脉

一款运行在浏览器中的 **3D 方块沙盒生存建造游戏**。在程序生成的荒原中采集资源、制作工具、建造据点、探索地下晶洞与失落遗迹、抵御夜行生物，并在最终防御战中修复能源塔、启动地脉核心、完成信号传输。

- 语言：TypeScript（严格模式）
- 构建：Vite 5
- 渲染：Three.js（区块网格面剔除、动态光照、阴影、天气粒子）
- 测试：Vitest（74 个单元/集成测试）+ Puppeteer 真实浏览器冒烟测试
- 存档：浏览器 `localStorage`，无后端

## 快速开始

```bash
npm install
npm run dev        # 打开 http://localhost:5173/
```

构建生产版本：

```bash
npm run build
npm run preview
```

## 测试

```bash
npm test           # Vitest：世界生成、物理、背包、制作、生存、敌人、建筑存档、任务事件
npm run smoke      # 真实 Chrome 冒烟（需先 npm run dev，并安装了 Chrome）
```

冒烟测试在真实浏览器中自动走完整条链路：进入游戏 → 移动 → 采集 → 制作工具/建筑 → 放置工作台/火盆/储物箱/门 → 击杀敌人 → 触发动态事件 → 保存 → 继续游戏（含坏档保护）→ 死亡掉落 → 通关结局。

## 推荐演示

- **推荐世界种子：`WASTELAND-7`**（固定种子，地形与遗迹位置完全一致，方便重复录屏）
- 留空种子则随机生成。
- 一个昼夜约 7 分钟，按界面顶部任务指引，10–15 分钟可完成一次完整演示：
  1. 砍棘木、敲碎石 → 制作燧石切割斧、石质采集锤；
  2. 制作并放置 **工作台、火盆、储物箱**（靠近出生点火盆即可取暖）；
  3. 向下挖掘进入洞穴找到 **地下晶洞**，获取能量晶体；
  4. 工作台合成 **塔体修复件**，跟随屏幕上的方向/距离指引前往 **废弃能源塔** 修复；
  5. 前往 **失落观测站**，打开站内储物箱取得地脉坐标盘；
  6. 制作 **地脉探测器** 与 **信号传输芯片**；
  7. 到地脉核心启动最终事件，坚守三波敌人完成传输。
- 结局按准备程度（建筑、击杀、生存天数、任务进度）分为 `S 地脉启明 / A 微弱回响 / C 孤注一掷`。

## 游戏系统

- **世界生成**：确定性值噪声（mulberry32 + 3D 值噪声）生成草原、灰岩、流沙、水域、高岭、霜结峰顶；洞穴、矿脉、树木、碎石、韧须草、废墟；区块 16×16×64，随玩家移动流式加载/卸载。
- **特殊地点**：废弃能源塔、地下晶洞（晶体矿+发光空腔）、失落观测站（储物箱含坐标盘）、地脉核心——都包含资源、机关、敌人或任务互动，非装饰。
- **方块（30+ 种）**：土、岩、沙、砾、水、棘木、叶、木板、砖、玻璃、合金板、深脉矿、碎矿、发光晶体、能源方块、工作台、火盆、储物箱、防护门、晶能灯、遗迹残块/蚀化金属等；硬度、工具需求、掉落、发光、地形移动惩罚各不相同。
- **工具（5+ 种及升级线）**：采集锤、切割斧、挖掘钻（各有 T1/T2）、照明棒、修理器，另有废铁短刃、晶刺投矛（远程）、两档护具；工具有耐久、效率与伤害，归零损坏，可用修理器修复。
- **制作**：29 个配方，校验材料、工作台距离、任务解锁阶段；失败会给出“材料不足 / 需要工作台 / 需要推进任务”的明确提示。
- **背包**：24 格容量 + 8 格快捷栏，同类堆叠、拆分一半、丢弃（真实掉落到场景中可再拾取）、背满无法拾取。
- **生存**：生命、体力、饱食、体温、照明安全值；冲刺/跳跃/挖掘/战斗消耗体力；饥饿、失温、过热、黑暗都会造成真实伤害；火盆、晶能灯、室内、护具、暖饮、食物均有实际效果。
- **昼夜天气**：完整昼夜光照/天空颜色/雾变化；晴天、暴雨、沙尘、极寒四种天气实际改变温度、能见度（雾+粒子）、移速与敌人活跃度。
- **敌人**：尘行者、洞穴噬兽、遗迹哨卫（夜行）三种行为与数值不同的敌人，具备巡逻→发现（视线检测）→追击→攻击（有冷却）→脱离返回的完整状态机，受击闪白、死亡掉落，无法穿过墙体，玩家可近战或投矛远程攻击；实体方块（砖墙、关闭的门等）会遮挡视线并立即打断攻击，玻璃、水体等透明材质不遮挡。
- **动态事件（8 种）**：资源枯竭（真实移除资源点）、据点遭袭（敌人在据点生成）、天气突变、洞穴坍塌（落石封路）、能源泄漏（熄灭发光方块）、商旅出现（给补给）、遗迹机关（唤醒哨卫）、敌人迁徙；结果写入日志，部分带倒计时。
- **建筑**：墙体/地板/屋顶/窗/门（可开合、开门无碰撞）/储物箱（18 格共享存储）/工作台/火盆/能源装置；建筑有耐久，可被敌人攻击削减、用修理器修复；浮空与身体重叠位置禁止放置。
- **死亡**：可在设置中选择掉落全部/一半/保留，显示死因与损失，在据点重生。
- **存档**：种子、玩家位置与状态、背包/快捷栏、时间天气、方块编辑（含建筑耐久/门状态）、箱子、敌人、任务阶段、事件日志、统计数据、设置；每 60 秒自动保存，返回主菜单自动保存；坏档会明确提示并清除，不会白屏。

## 项目结构

```
index.html               菜单/HUD/背包/制作/储物箱/日志/暂停/死亡/结局界面
src/
  main.ts                入口：菜单按钮、设置、游戏启动/继续
  style.css              全部界面样式
  game.ts                主引擎：输入、采集/放置/交互、战斗、事件、任务、最终战、存档
  ui.ts                  HUD/背包/配方/箱子/日志/死亡界面渲染
  core/                  与渲染无关的纯逻辑（可完整单元测试）
    rng.ts               可复现随机数与 3D 值噪声
    blocks.ts            方块注册表（硬度/工具/掉落/发光/建筑耐久）
    items.ts             物品/工具/护具/食物/任务道具
    inventory.ts         背包：堆叠、拆分、容量、快捷栏、耐久、材料支付
    recipes.ts           配方与制作校验
    world.ts             区块生成、生物群系、洞穴、矿脉、特殊地点、编辑持久化
    player.ts            第一人称 AABB 碰撞物理、跳跃/冲刺/蹲下、体素 DDA 射线
    environment.ts       昼夜时钟、天气、环境温度
    survival.ts          五维生存状态结算、进食、伤害
    enemies.ts           敌人状态机、视线、追击/攻击、生成
    quests.ts            10 阶段主线、准备度与结局评级
    events.ts            8 种动态事件及其世界效果
    save.ts              localStorage 存档读写与坏档保护
  render/
    mesher.ts            区块网格构建（六面剔除、面明暗、透明水体）
    scene.ts             Three.js 场景、天空/光照/雾、天气粒子、区块流式网格、光照
    entities.ts          敌人、掉落物、投矛的实体渲染
test/                    Vitest 测试（8 个文件，74 个用例）
scripts/
  smoke.mjs               Puppeteer 浏览器冒烟入口
  browser-harness.js      注入页面的测试动作
```
